# SV Store — от мастера Святослава

Магазин приложений для Android TV и отдельный SV Admin для управления с телефона.

## Установить

- [SV Store 0.6.0 — на приставку](https://raw.githubusercontent.com/slawa99-prog/sv-store-catalog/refs/heads/main/downloads/SV-Store-0.6.0.apk)
- [SV Admin 0.4.0 — на телефон владельца](https://raw.githubusercontent.com/slawa99-prog/sv-store-catalog/refs/heads/main/downloads/SV-Admin-0.4.0.apk)
- [Контрольные суммы](downloads/SHA256SUMS.txt)

Установите поверх прежних версий, без удаления. Подпись APK сохранена, минимум Android 13. Store 0.5.0 может получить новую версию через встроенное обновление магазина. Для более старых версий установите APK вручную.

## Что нового

- Подробные карточки, иконки до установки и до пяти скриншотов.
- Сведения об управлении пультом, регистрации и оплате — задаются владельцем.
- Инструкция для каждого приложения на экране телевизора и QR-код на отдельную ссылку.
- Статусы «Возможны проблемы» и «Временно не работает», пояснение и рекомендуемая замена. Уже установленные приложения не удаляются.
- Выбор нескольких приложений или обновлений, последовательная очередь с прогрессом, паузой после текущего приложения и повтором только неудачных.
- Понятные ошибки с действиями: память, разрешение установки, интернет, несовместимый APK.
- В Admin — предпросмотр карточки и перечня изменений до публикации.

Подборка «С чего начать» не добавлена. Иконки пяти текущих приложений извлечены из их APK; инструкции, скриншоты и остальные сведения можно заполнить через Admin → «Редактировать» / «Изображения».

Во всех категориях появилась постоянная плашка «От мастера Святослава» с подписью «Лично подбираю и проверяю приложения для вашей приставки». Она отображается отдельно от новостей. Имя владельца также указано в помощи рядом с QR-кодом. Плашка обозначает авторство подборки, но не блокирует копирование APK.

В настройках есть отдельное **Обновление SV Store**. Для автоматической установки включите **Установка через root**, разрешите Magisk, затем включите **Обновлять SV Store автоматически**. Обновления выполняются во время простоя через сеть без тарификации. Android определяет момент запуска; немедленная установка не гарантируется. При отключённом питании обновления не выполняются.

Без root новая версия устанавливается кнопкой внутри Store с подтверждением Android. Настройки магазина сохраняются при обновлении. Автообновление самого магазина и остальных приложений включается отдельно; оба разрешения по умолчанию выключены.

## Публиковать новую версию магазина

В SV Admin откройте **Обновление SV Store → Выбрать APK SV Store**, выберите новый полный APK с прежней подписью и увеличенным versionCode, затем нажмите **Опубликовать**. Store получит предложение из подписанного каталога. Сам магазин не появляется среди обычных карточек и не увеличивает их количество.

Admin проверяет пакет и сертификат перед загрузкой. Store проверяет хеш, пакет, версию, совместимость Android и исходную подпись APK. Понижение версии и замена другим ключом блокируются. Если автоматическая установка не удалась, повтор той же версии выполняется не раньше чем через шесть часов.

После обновления Admin загрузите опубликованный каталог перед новой работой. Если в нём уже есть локальные правки, сначала экспортируйте их: загрузка заменяет черновик. Публикация проверяет предыдущую версию файла и не перезаписывает чужие изменения.

## Обычные приложения и помощь

Добавляйте APK и категории в Admin, затем нажимайте **Опубликовать**. Ссылку на канал задайте в **Объявление и канал помощи**. В Store оставлены категории, MOD, помощь с QR-кодом и настройки обновлений. Диагностики, восстановления и пользовательского редактора адреса каталога нет.

Открытый Store проверяет каталог примерно раз в минуту; кэш GitHub может задержать изменения. Адрес каталога уже задан:

```text
https://raw.githubusercontent.com/slawa99-prog/sv-store-catalog/refs/heads/main/catalog.json
```

Для первого подключения нового телефона нужен GitHub fine-grained token с правом **Contents: Read and write** для этого репозитория и исходный ключ подписи каталога `SV_Store_PRIVATE_SIGNING_KEY.pem`. Token вставляйте только в Admin. Приватные ключи и token не входят в APK и публичный репозиторий. Истечение token влияет на новые публикации, а опубликованные файлы остаются доступны.

Admin сначала публикует APK в GitHub Releases, затем обновляет подписанный каталог. Первоначальные установщики Store и Admin размещены в `downloads/`.
