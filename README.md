# SV Store

Магазин приложений для Android TV и отдельное приложение SV Admin для владельца.

## Установить

- [SV Store 0.4.2 — на приставку](https://raw.githubusercontent.com/slawa99-prog/sv-store-catalog/refs/heads/main/downloads/SV-Store-0.4.2.apk)
- [SV Admin 0.2.1 — на телефон владельца](https://raw.githubusercontent.com/slawa99-prog/sv-store-catalog/refs/heads/main/downloads/SV-Admin-0.2.1.apk)
- [Контрольные суммы SHA-256](downloads/SHA256SUMS.txt)

Минимум Android 13. Устанавливайте поверх прежних версий: используется прежняя APK-подпись.

В Store 0.4.2 адрес каталога уже задан. Если в старой версии был сохранён пустой адрес, он также заменяется адресом этого магазина. Введённый ранее собственный адрес сохраняется.

## Состояние каталога

Подписанный каталог опубликован и доступен. Его наполнение владелец меняет через SV Admin.

Адрес каталога:

```text
https://raw.githubusercontent.com/slawa99-prog/sv-store-catalog/refs/heads/main/catalog.json
```

Открытый Store проверяет изменения примерно раз в минуту. Кэш GitHub может задерживать публикацию. Появление карточки и установка APK — отдельные действия.

## Первое подключение SV Admin

1. В GitHub создайте **Fine-grained personal access token** для своего аккаунта. Выберите **Only select repositories → sv-store-catalog**, затем **Contents → Read and write**. Остальные разрешения не нужны. Выберите срок действия; после истечения token заменяется в Admin.
2. Откройте SV Admin → **Подключить GitHub**. Репозиторий: `slawa99-prog/sv-store-catalog`. Вставьте полный токен непосредственно в приложении на своём телефоне. Строка Fine-grained token начинается с `github_pat_`: используйте кнопку копирования рядом с токеном на GitHub. Имя «SV Admin» и ссылка на страницу не подходят.
3. Нажмите **Импортировать ключ подписи** и выберите ранее полученный `SV_Store_PRIVATE_SIGNING_KEY.pem`.
4. Добавьте самостоятельный APK, название, описание и категорию. Нажмите **Опубликовать**.
5. На приставке откройте Store → Настройки → **Обновить каталог** и проверьте новую карточку.

[Официальная инструкция GitHub по созданию token](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens).

Token и приватный ключ хранятся зашифрованными на телефоне владельца. Не добавляйте их в этот публичный репозиторий. Установочные APK не содержат секретов.

SV Admin публикует добавляемые APK в GitHub Releases, затем обновляет подписанный `catalog.json`. Начальные установщики Store и Admin размещены в `downloads/`.

## Интерфейс

Категории приложений, отдельный раздел MOD, помощь с QR-кодом канала. Диагностики и восстановления нет. В «Помощи», «Настройках» и «Обновлениях» поиск приложений скрыт. Ссылку своего канала владелец добавляет в Admin → «Объявление и канал помощи».

## Проверено

Для Store 0.4.2 прошли 7 тестов интерфейса: фильтр, включая увеличенный шрифт, управление пультом, категории и MOD, QR-код из каталога, отсутствие поиска в служебных разделах и упрощённые настройки. Нативная отрисовка экранов просмотрена. Подпись APK совпадает с предыдущим Store. Установку новой версии на физической приставке ещё нужно проверить.

## SV Admin 0.2.1

Исправлена форма подключения: ошибки формата показываются у поля токена и отличаются от ошибок прав доступа. Пробелы, переносы строк и невидимые разделители копирования удаляются автоматически. Есть переключатель «Показать токен»; по умолчанию токен скрыт. Проверено: 14 сценариев ввода, 35 интеграционных проверок на тестовом соединении и 8 тестов интерфейса. Подпись APK сохранена для установки поверх 0.2.0. Владелец уже подключил Admin и публикует каталог.

Срок токена относится только к публикации из Admin. Его истечение не отключает чтение публичного каталога и скачивание опубликованных APK.

## SV Store 0.4.2

Обновлён дизайн: графитовые поверхности, мятный акцент, новые карточки и чёткое выделение пульта. Исправлены обрезанный текст фильтра и значок инструментов. В помощи оставлен QR-код, в настройках — обновление каталога и параметры установки/автообновлений. Адрес каталога и канал не редактируются на приставке; канал задаётся в Admin.

Установите APK поверх прежнего Store. Кнопка «Обновить каталог» обновляет наполнение, а для нового интерфейса требуется новая версия приложения. Admin остаётся версии 0.2.1.
